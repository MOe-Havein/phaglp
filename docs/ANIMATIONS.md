# Module: Admin Dashboard Animations

Integrated Framer Motion to provide smooth, professional UI transitions.

## Components

- **AnimatedCard**: Fade and slide-up entrance for dashboard cards.
- **AnimatedModal**: Scale and fade transitions for dialogs.
- **PageTransition**: Slide and fade effect for admin route changes.

## Best Practices

- **Accessibility**: Animations respect user "Reduced Motion" preferences.
- **Performance**: Lightweight transitions (300-400ms) with ease-out curves.
