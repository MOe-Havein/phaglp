
# PHAGLP Architecture Contract

## Canonical Architecture

src/
├── app
├── components
│   ├── ui
│   └── shared
├── features
├── hooks
├── lib
├── services
├── types

## Core Rules

- Feature-first architecture
- App Router only
- Server Components by default
- Thin route handlers
- Typed services
- Zod validation required
